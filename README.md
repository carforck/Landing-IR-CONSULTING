# Landing IR Consulting

Landing de IR Consulting — consultoría estratégica y financiera (Isabel Rodríguez, Cartagena).

- Stack: Vite 5 + React 18, lucide-react y Phosphor Icons.
- Contenido único: `src/data.js`. Medios con licencia libre: `src/media.js` y `public/media/CREDITOS.md`.
- Marca (logo, isotipo y paleta, en SVG y PNG): `brand/`. Se regeneran con `python3 brand/gen.py`.

## Comandos

```bash
npm run setup   # idempotente: instala solo si cambió package.json/lockfile
npm run dev     # http://localhost:5181 (y en la red local)
npm run build
```
